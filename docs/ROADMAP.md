## 下一阶段

以下是仍待完成的计划，不作为现有能力介绍；已经实现的部分列在上表。

### 恢复证据

- 在现有文件检查与导出功能上，增加完整恢复后的 Git 对象、文件清单核对和验证回执。
- 支持导出单个恢复点，便于离线保管和在另一台 Mac 上导入。

### Agent 处理方案

- 将已验证的 Git 修复过程保存为可复用方案，记录适用条件、命令边界和验证命令。
- 为保存的方案提供执行前的读取、写入与权限清单。

### 发布闭环

- 将现有可选公证流程纳入常规发版验收，完成 notarize、staple 与 Gatekeeper 检查。
- 对上一正式版本执行“检查更新 → 下载 → 安装 → 重启 → 版本核对”的自动回归。
- 将发布页、Appcast、DMG 校验值与应用内更新说明的一致性检查纳入自动回归。

## 移动端与远程连接（已暂停）

2026 年 9 月 13 日暂停开发，保留已有源码，暂不安排上线时间。以下均为待完成计划，不属于当前正式版能力。

移动端使用 Swift 开发，后端使用 TypeScript / Node.js。计划通过公网连接，让手机在蜂窝网络或其他 Wi-Fi 下访问已配对的 Mac，不要求处于同一局域网，也不要求用户开放路由器端口。

### 1. 后端服务

- 完成账号接入、设备配对、授权范围、设备列表与撤销授权。
- 补齐消息投递回执、离线任务、过期清理、限流与服务运维；明确任务已送达、正在执行和执行完成的区别。
- 接入任务结果与异常通知，安排 APNs 推送、部署配置、密钥管理和安全验收。
- 服务端负责设备连接和消息转发，仓库操作由获授权的 Mac 执行。

### 2. Mac 后台连接器

- 接入现有后台助手，主程序打开或退出时都能保持连接，避免重复启动监控或扫描仓库。
- 完成断线重连、任务记录持久化、重复投递处理与取消；明确显示离线、休眠、等待执行和执行结果。
- 接入真实仓库状态、Diff、灾备记录和 Agent 任务，不停留在接口或命令定义。
- 按设备和仓库授予操作权限；涉及写入、推送或恢复的操作，绑定待执行内容与仓库状态确认，状态变化后重新核对。

### 3. Swift 移动端

- 开发项目列表、仓库详情、任务进度、通知与设备管理。
- 支持 GitHub 远端协作，以及连接 Mac 后查看本地仓库和处理 Agent 任务；区分无需 Mac 的功能和需要 Mac 在线的功能。
- 逐步接入 Diff、Issue、PR、Actions、翻译、任务审批与灾备信息，保留各操作的实际结果和失败原因。

### 4. 跨网络验收

- 使用真实 Mac 和 iPhone / iPad，在不同网络下验证配对、状态读取、任务执行和结果通知。
- 覆盖主程序退出、Mac 休眠、断网重连、服务重启、重复消息、任务取消和撤销授权。
- 完成端到端验证后，再安排部署、移动端测试分发与正式发布。
