# GitGatto 图标设计稿

- 视觉基准：圆角、黑色单线、统一线宽与光学尺寸
- 全量清单：128 枚基础图标，另含 AI 编写专属图标
- Agent：猫耳终端轮廓，与其余图标统一为黑色
- 当前状态：129 枚图标已接入应用资源

## 文件

- `core-agent-monochrome.png`：核心 15 枚图标定稿
- `ai-writing-selected-c.png`：AI 编写专属图标定稿
- `batch-1-sheet.png` ～ `batch-8-sheet.png`：全量图标设计稿
- `applied-light-preview.png`、`applied-dark-preview.png`：应用资源在浅色与深色下的 28 px 检查图
- `manifest.json`：每组图标的行优先顺序
- `supplemental.json`：独立补充图标
- `SHA256SUMS`：设计稿校验值
- `../../../scripts/build-image2-icons.py`：从设计稿生成透明 256 px 应用资源

彩色 GitHub 猫主题稿保存在 `../references/future-theme-colorful-github-cat.png`，供后续主题开发使用。
