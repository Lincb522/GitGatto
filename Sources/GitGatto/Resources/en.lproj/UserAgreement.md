# GitGatto User Agreement

Effective: August 27, 2026

## 1. Scope

This agreement covers the GitGatto macOS client. By using the software, you agree to these terms for local Git repositories, GitHub projects, and tasks executed through local Agent CLIs.

## 2. Accounts and authorization

GitGatto reuses existing Git, GitHub CLI, and Agent CLI sessions. Connect only repositories and accounts you own or are authorized to manage. You remain responsible for system Keychain, SSH key, and third-party CLI security.

## 3. Local and remote operations

Staging, commits, branch switches, discards, pulls, pushes, forks, and pull-request replies change local or remote state. GitGatto shows the target and result where practical; verify the repository, branch, and changes before execution. Remote writes run only after an explicit action.

## 4. Agent output

Agent-generated commit messages, code changes, translations, and reply drafts may be incomplete or inaccurate. Review all output before committing, pushing, or publishing it. Agent output is not professional, legal, or security advice.

## 5. Updates

The built-in updater retrieves packages from GitHub Releases and requests confirmation before installation. Updates may fix defects, change compatibility, or alter features. Release notes are shown before installation.

## 6. Acceptable use

Do not use GitGatto to access unauthorized data, bypass third-party restrictions, damage repositories, or infringe rights. GitHub, Git, and Agent CLI terms also apply.

## 7. Ending use

You may stop using and delete the application at any time. Removing the app does not delete local repositories, remote projects, or third-party CLI data.

## 8. Changes

Material changes will be included with release notes. Continued use of a new version indicates acceptance of the updated agreement.
