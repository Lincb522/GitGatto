## Improved

- Choose commit and push, create PR, release, or a custom goal, then review the scope and start execution directly.
- Goals now focus on the current task and its phases. History is separate; detailed steps, logs, and metadata expand on demand.
- Agent preparation and repair stay on the goal page. Successful runs continue with commit and push; merging, publishing, and installing still require separate confirmation.
- Remote checks update automatically when goal monitoring is enabled. Edited commit messages are saved when continuing execution.
- Updated goal controls and usage guides in all 11 languages.

## Fixed

- Failed or cancelled Agent repairs retain their error and retry action. A failed repair-plan save preserves the previous state.
