## Added

- Repository summaries can now be collapsed manually and automatically compact while reading documentation.
- Update actions now animate checking, available-update, and completed-check states.
- Added a complete version history with every published GitHub release and its notes.

## Improved

- Soft Glass and Console themes now reserve consistent space for window controls.
- The About window now uses a compact layout with window controls integrated into its header.
- Checking for updates now starts immediately without opening Update Center.
- Update Center now shows the latest release notes first and links to the full version history.
- Added an About shortcut to the Console theme toolbar.

## Fixed

- Fixed current versions being reported as failed update checks.
- Fixed reversed text in the Soft Glass About window.
- Fixed excessive vertical space when the About window restored an older size.
