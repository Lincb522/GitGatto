## 新增

- 新增“曜幕”主题，工作区、设置与关于窗口使用玻璃材质与低饱和环境光，支持深浅色外观。
- 变更中心支持按文件或 Diff 分块整理改动，分组创建提交，并在执行前创建恢复点。
- 代码缘由可从文件行追溯提交，关联对应的 Pull Request、Issue、Review 与 Checks。
- 故障胶囊可将补丁、未跟踪文件、基准提交、失败输出和工具版本导出为 `.gatto`，校验后在独立 worktree 中恢复。
- 外部 Agent 活动记录保存 Git 引用和文件状态变化，以及当时在仓库目录中运行的 Agent 进程与关联强度。

## 改进

- 控制台主题采用工具轨、仓库目录与工作区标签，文件列表和差异区使用紧凑排版。
- 翠影主题将文件列表与提交区放在右侧，为差异阅读保留连续工作面。
- 银页主题采用一体式分组侧栏、横向文件选择和独立提交面板；收起侧栏后保留图标列。
- 仓库切换支持搜索与活跃时间分组，当前仓库固定显示，较早的仓库分区可折叠。
- 设置中的主题预览与实际布局一致，次要文字提高对比度，窄窗口中的操作按钮适配长文本。
- 更新失败时保留底层错误与恢复建议，更新助手启动超时会显示对应提示。
