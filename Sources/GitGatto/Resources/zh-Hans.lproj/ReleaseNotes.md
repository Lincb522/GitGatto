## 新增

- 应用仓库支持快捷安装：DMG 与 ZIP 使用本机安装流程，其他发行包由 Agent 检查、安装并显示阶段进度。
- 开发工具中心收录 63 种常用工具，可识别本机安装状态、检查 Homebrew 可升级版本，并交给 Agent 安装或升级指定工具。

## 改进

- 文本、Markdown 与 HTML 翻译的单次处理上限延长至 3 分钟；HTML 按批次独立计时。
- 开发工具扫描采用分批并发，并识别 Homebrew keg-only 路径。
- Sparkle 更新组件升级至 2.9.6，更新失败时显示底层原因、错误域与错误代码。

## 修复

- 移除会强制重启 Sparkle 安装进度进程的旧兼容逻辑，避免下载完成后安装连接被中断。
