## 新增

- 应用仓库详情与发布内容支持 Agent 翻译，并保留译文供后续直接切换。
- 工作区变更、提交历史和文件历史支持直接预览图片、视频与 SVG 内容。
- 项目、开发者和应用仓库搜索支持继续加载更多结果。

## 改进

- 全部界面图标替换为 Zappicon 矢量资源，改善深浅色和小尺寸显示。
- 为项目、GitHub、Agent、下载、更新和详情页面补齐加载状态。
- 优化 GitHub 语言图标的小尺寸渲染清晰度。
- 拉取、提交和推送进度直接显示在对应按钮中，移除重复的同步动画。

## 修复

- 项目 Agent 最长可持续运行 15 分钟，构建和测试任务不会再在 150 秒时被过早终止，并可随时手动取消。
