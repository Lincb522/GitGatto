## 新增

- 选择文件夹即可建立本地 Git 仓库，并创建公开或私有的 GitHub 仓库；支持 Agent 自动填写和手动配置。
- 已有本地仓库可以创建或关联远端、配置当前分支上游；可交给 Agent 处理，也可手动操作。上传已有提交前会展示确认。
- GitHub 项目与远端详情增加公开／私有切换入口，切换前检查管理权限并提示影响。
- 命令搜索新增新建仓库、Agent 一键配置和手动配置；文件详情增加“文件操作”菜单。

## 优化

- 仓库添加、暂存、分支重命名、提交操作、贮藏删除、工作树移除及刷新等常用入口增加文字，单文件暂存不再依赖鼠标悬停。
- 操作区按可用空间换行，沿用各主题样式；补齐新增操作的多语言文案。
- 仓库配置完成后更新分支与远端状态，保留当前页面和提交草稿；Agent 命名遇到重名时重新生成候选名称。

## 修复

- 修复 Agent 编辑当前仓库时，部分暂存按钮仍可点击但没有响应的问题。
- 修复窄窗口中提交详情加载占位条撑宽面板、工作树 Agent 模式文字截断，以及恢复分类出现无关创建入口的问题。
- 变更意图、文件追溯等仓库分析页面的错误提示接入统一说明与恢复建议，敏感信息在诊断内容中脱敏。
