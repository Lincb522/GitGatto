## 新增

- 灾备保护扩展到所有已管理的本地仓库，监控外部 Agent、终端 Git CLI 与脚本造成的仓库变化。
- 持续维护外部操作恢复基线，识别整库删除、文件删除、未提交内容丢失以及分支、HEAD 和暂存区异常。
- 灾备中心增加风险事件卡片，可查看原始错误、受影响路径与仓库状态，并直接打开对应恢复点。

## 改进

- 恢复点采用原子写入、提交标记、内容校验和文件系统同步；异常退出后仅恢复完整事务。
- 每个仓库最多保留三份滚动恢复点；检测到高风险操作后冻结最近恢复点，避免现场被后续备份覆盖。
- GitGatto 内置 Agent 在写入前强制创建恢复点，并在完成后核对删除、覆盖与 Git 状态变化。

## 修复

- 修复高负载下 FSEvents 延迟造成的暂存状态和灾备事件漏刷新。
- Homebrew 超时从进程实际启动后计算，不再把调度等待误判为执行超时。
