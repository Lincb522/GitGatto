## 改进

- 拉取与推送按钮默认显示为紧凑圆角矩形，悬停后横向展开显示文字，执行时沿完整外轮廓显示进度光带；克隆与 Fork 并克隆按钮的左侧强调色状态块会在悬停时展开，执行中显示状态与轮廓进度；翻译保留 Download Button 的分层滑动与完成反馈；错误处理中的 Agent 按钮采用扁平文字流光，README Agent 使用文件夹、纸张与铅笔动效。
- 应用仓库截图支持自动轮播与手动切换；README 原文、译文和重写预览支持卡片切换。
- Star 操作使用强调色按钮，合并 GitHub 标识、当前 Star 数与状态动画，悬停时显示一次横向高光；新增仓库、网络状态与 Agent 工具栏补齐对应的交互反馈。
- README Agent 可直接处理尚未添加到本地的 GitHub 项目，运行中可从按钮取消；Star 更新状态沿按钮外框显示进度光带，侧边栏扫描入口同步放大。
- AI 翻译使用与 README Agent 一致的控件结构，并显示翻译图标与“正在翻译”状态；拉取和推送使用与克隆一致的滑动强调块、方向动效和轮廓进度。
- 实时状态刷新会跳过未变化的数据，页面切换延后详情加载，轻毛玻璃面板的阴影与滚动内容分离。
- 应用仓库的详细介绍支持 Agent 翻译并缓存译文；截图只展示仓库实际提供的图片。
- 暂存与取消暂存会立即更新工作区，并只刷新实时 Git 状态；代码预览复用语法分析结果，媒体预览不再阻塞差异内容显示。
- 错误报告同时保留完整原始输出、错误代码、中文解释与对应处理建议，并覆盖 Git、Agent、GitHub、文件和网络常见错误。

- 同步状态按仓库数据显示，待推送使用警示色，后台刷新错误保留为诊断提示。
