## 新增

- 支持从 GitHub Releases 读取版本记录和更新日志。
- 更新中心可在应用内查看 GitHub 发布页，不会跳出到浏览器。
- 默认专业主题与轻毛玻璃主题可独立切换，并分别使用对应的窗口、布局和控件样式。

## 改进

- 项目工作区、暂存区、分支和远端同步状态持续读取当前选中的真实仓库。
- GitHub 项目详情支持 README、图片、仓库内链接、目录和代码浏览。
- 项目 Agent 与翻译使用独立 CLI 通道，并保留对话、操作记录和译文。

## 修复

- 修复默认主题被轻毛玻璃主题覆盖的问题。
- 修复品牌图标与字标在小尺寸显示时的锯齿、间隙和对齐问题。
