## 新增

- Agent 支持自定义 OpenAI 兼容 API 和 DeepSeek API，项目与翻译可分别配置，密钥保存在系统钥匙串；可读取模型列表、检测接口能力，并流式显示回复。
- 接入 DeepSeek Harness（dsh）、Cursor Agent、GitHub Copilot CLI 和 Qwen Code。API Agent 可读取项目、执行命令、受控修改文件，并参与工具安装与升级。
- 命令面板支持固定常用入口、查看最近使用，并用当前界面语言搜索功能。
- Diff 支持按行或按块暂存、撤销暂存，选中的改动可直接交给 Agent 编排提交。
- 可从当前改动、Issue、PR 和失败的 GitHub 检查创建目标，保留相关上下文；目标可在提交前运行已有的项目验证命令。
- Issue、PR 回复和审阅支持本地草稿，切换项目或重新打开后可继续编辑；收件箱集中显示需要处理的提及、审阅和失败检查。
- 文件历史支持从文件或行定位到对应提交及代码缘由；恢复历史版本前可查看与当前文件的差异。
- 灾备中心可检查恢复点内容、对比文件，并将所选文件导出到新目录。
- 开发工具新增 Web、Python、Swift、Rust/C++、Docker、SQL/Redis 六类工具组合，显示安装影响范围和配置回执。
- 设置支持为每个仓库选择自动、活跃或低频监控策略。

## 改进

- 提交编排集中显示改动范围、提交预览和执行进度；刷新、重试和重新编排保留选区，只在明确切换范围后使用全部改动。
- 切换分支前展示未提交文件，可先保存工作现场再切换；提交草稿、Agent 输入和选中文件按仓库与分支保留。
- 主仓库和工作树的 Agent 任务分别运行，切换仓库后仍可返回查看进度、结果或取消任务。
- 冲突处理可逐块选择当前、传入或两侧内容，编辑保存后继续合并；回归取证可选择已有项目命令或手动判定。
- 安装、升级任务重开后保留记录；中断任务先检查实际安装状态，再继续未完成的配置。多仓库同步可只重试失败项。
- 翻译统一提供原文、译文、重试与取消入口，补充短文本和混合语言检测；翻译结果检查代码、链接、路径及数字，检查失败时保留原文。
- 减少连续保存、原子写入和仓库切换引起的重复扫描；后台监控按电源状态调整频率，未变化的历史与活动数据继续复用。
- 设置修改先保留为草稿，保存后只更新受影响的服务；错误详情可展开，常见失败直接提供重试或恢复入口。
- 更新中心区分检查、下载、校验和安装阶段，失败后可复制脱敏诊断信息，或打开版本页下载。
- 补齐新增功能的使用指南、11 种语言文案及缺失图标，调整窄窗口、长标题和从右向左语言的布局。

## 修复

- 修复后台刷新或发送完成回调覆盖新草稿、取消后旧任务继续覆盖当前状态的问题。
- 修复选区提交时带入未选中的暂存内容、重新编排后丢失选区的问题；内容已变化时要求重新选择。
- 修复翻译重试使用错误目标语言、旧请求结果覆盖新请求的问题。
- 修复回车执行命令时，最近使用排序变化可能导致执行另一项的问题。
- 修复分支切换及工作现场恢复可能覆盖同名忽略文件的问题；恢复失败时保留已保存的现场和错误信息。
