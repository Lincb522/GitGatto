## 新增

- 仓库工具集中管理分支、标签和远程仓库，并可比较引用、从 Reflog 创建恢复分支。
- 提交历史支持修订、重排、合并、拆分、拣选、撤销与重置；重写前创建恢复点，并阻止改写已经发布的提交。
- 多仓库同步可批量获取、拉取和推送，分别显示待拉取、待推送、分叉、冲突与失败状态，并可重试失败项。
- GitHub 收件箱汇总待审阅、要求修改、提及、检查失败、冲突与可合并项目；Issue 可在应用内创建、编辑、关闭、重新开启和评论。
- 全局命令面板可快速切换页面、仓库与分支并执行常用 Git 操作；提交搜索支持按 SHA、作者、路径、改动文本、日期和引用组合筛选。
- Agent 可根据 Pull Request 的差异、审阅记录和讨论起草回复，也可根据 Issue 正文、标签与评论起草同语言回复；草稿可编辑，确认后才会发布。
