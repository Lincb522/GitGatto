# GitGatto 用户协议

生效日期：2026 年 8 月 27 日

## 1. 适用范围

本协议适用于 GitGatto macOS 客户端。使用本软件即表示你同意按照本协议管理本地 Git 仓库、GitHub 项目以及由本机 Agent CLI 执行的任务。

## 2. 账户与授权

GitGatto 复用 Git、GitHub CLI 和 Agent CLI 的现有登录状态。你应仅连接自己拥有或获准管理的仓库与账户，并负责维护系统钥匙串、SSH 密钥和第三方 CLI 凭据的安全。

## 3. 本地与远端操作

暂存、提交、分支切换、丢弃改动、Pull、Push、Fork 和 Pull Request 回复会改变本地或远端状态。GitGatto 会在可行范围内显示操作对象和结果；执行前仍应确认仓库、分支和改动内容。远端写入只在你触发明确操作后执行。

## 4. Agent 输出

Agent 生成的提交信息、代码修改、翻译和回复草稿可能不完整或不准确。你应在提交、推送或发布前审阅结果。Agent 输出不构成专业、法律或安全建议。

## 5. 更新

应用更新由内置更新组件从 GitHub Releases 获取，并在安装前请求确认。更新可能修复缺陷、调整兼容性或改变功能；更新说明会在安装前显示。

## 6. 可接受使用

不得使用 GitGatto 访问未授权的数据、规避第三方平台限制、破坏仓库或侵犯他人权利。使用 GitHub、Git 和第三方 Agent CLI 时，还应遵守相应服务条款。

## 7. 终止使用

你可以随时停止使用并删除应用。删除应用不会自动删除本地仓库、远端项目或第三方 CLI 中的数据。

## 8. 协议变更

协议发生实质变化时，将随版本更新说明发布。继续使用新版本表示接受更新后的协议。
