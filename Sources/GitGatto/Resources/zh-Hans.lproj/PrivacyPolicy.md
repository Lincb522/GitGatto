# GitGatto 隐私政策

生效日期：2026 年 8 月 27 日

## 1. 本地优先

GitGatto 的仓库目录、设置、Agent 对话、操作记录和文档译文默认保存在你的 Mac 上。应用不内置广告、用户画像或分析统计服务。

## 2. 凭据

GitGatto 通过系统提供的 Git、SSH、GitHub CLI 与 Agent CLI 使用现有登录状态，不读取、展示或保存访问令牌、密码和私钥。凭据仍由系统钥匙串或相应 CLI 管理。

## 3. 网络请求

当你使用 GitHub 搜索、项目读取、Fork、克隆、Pull Request、远端同步、Agent 或翻译功能时，相关工具会向你配置的服务发送完成操作所需的数据。数据处理同时受 GitHub、Agent 提供方和仓库托管服务各自政策约束。

## 4. 更新检查

检查更新会通过 HTTPS 请求 GitGatto 的更新源。更新组件不启用系统画像上传；常规网络元数据仍可能由托管服务记录。

## 5. 本地数据管理

移除侧边栏中的仓库不会删除磁盘上的项目。卸载应用前，如需清理设置、对话或译文，可删除 GitGatto 的应用支持目录；该操作不会修改本地 Git 仓库。

## 6. 共享

GitGatto 不出售个人信息。只有在你主动执行远端操作、使用第三方 CLI，或法律要求时，数据才会由相应服务处理。

## 7. 变更与联系

政策变化会记录在版本说明与开源仓库中。问题可通过 GitGatto 开源仓库的 Issue 提交。
