تستخدم لقطات الشاشة بيانات توضيحية لعرض الواجهة؛ أسماء المشاريع والأعداد ليست مقاييس للاستخدام.

GitGatto عميل Git وGitHub أصلي لنظام macOS على Apple Silicon وIntel. إلى جانب إدارة المستودعات، يوفر نسخاً للتغييرات غير الملتزمة، وسجلات Agents الخارجية، وأهداف التسليم، والتحقيق في التراجعات، وإعداد أدوات التطوير.

<a id="why"></a>
## لماذا نطوّر GitGatto

بعد كتابة الكود تبقى تغييرات مختلطة، وتراجعات، وCI، ومراجعات PR وإصدارات. وقد يؤدي الانتقال بين المهام إلى نسيان المسودات والملفات غير الملتزمة.

تضيف Agents أسئلة أخرى: ماذا تغيّر ولماذا؟ ما الأدلة المتبقية بعد الفشل؟ وهل تعمل النتيجة التي أُعلن اكتمالها؟ يعالج GitGatto هذه المهام واستئنافها، بدلاً من الاكتفاء بأزرار لأوامر Git. يحتفظ بـGit النظام وأدوات CLI الموجودة، مع إتاحة التغييرات والأدلة ونقاط الاستعادة.

<a id="features"></a>
## الميزات المميزة

<a id="recovery"></a>
### نسخ العمل غير الملتزم ومراقبة التغييرات الخارجية

تُحفظ حزمة Git bundle ونسخ الملفات غير الملتزمة للمستودعات المحلية المضافة. تتجاوز النسخ المجدولة أو الناتجة عن تغييرات كبيرة المحتوى غير المتغير، مع إمكانية إنشاء نقاط يدوية. يحتفظ كل مستودع بثلاثة أجيال كحد أقصى.

يمكن إنشاء نقطة قبل كتابة Agent. تراقب الحماية الحذف وفقد التعديلات وتراجع المراجع وتعذر الوصول بعد التغييرات الخارجية، وتعرض الأسباب والمسارات. يمكن فحص الملفات ومقارنتها وتصدير المحدد منها أو الاستعادة إلى مجلد جديد؛ تغيير موقع النسخ ينقل المحتوى الموجود.

تعتمد استعادة انقطاع الكهرباء على آخر نقطة مكتملة. يُزامن المحتوى والفهرس مع القرص قبل علامة الاكتمال وتدوير النسخ القديمة. يعالج التشغيل التالي الكتابة المنقطعة. لا تُضمن استعادة التعديلات اللاحقة أو محتوى المحرر غير المحفوظ أو الملفات المستبعدة. لا تعترض الحماية كل أمر من التطبيقات الأخرى.

<a id="monitoring"></a>
### حالة المستودعات من شريط القوائم

اختر جميع المستودعات أو واحداً بصورة مستقلة عن النافذة: التغييرات وupstream والنسخ وActions والأهداف والنشاط اليومي. يعرض المؤشر المصغّر النطاق والعدد والتنبيهات، وتتبع اللوحة القابلة للتمرير سمة التطبيق. النشاط يعد الالتزامات والتغييرات المرصودة، لا ساعات العمل.

عند تفعيل المتابعة بعد الخروج، يتولى مساعد مستقل المراقبة والنسخ المجدولة ونسخ التغييرات الكبيرة والحماية وفق الإعدادات. عند إعادة فتح التطبيق يعيد المهام دون فحص مزدوج. الخيار معطل افتراضياً وقد يحتاج موافقة macOS.

التشغيل العام والقنوات وإظهار الرمز والفواصل منفصلة. إخفاء الرمز لا يوقف النسخ الخلفية المفعلة؛ تعطيل المحرك أو الحماية يوقف المهام المقابلة.

<a id="goals"></a>
### استئناف هدف تسليم

اختر الالتزام والدفع، أو إنشاء PR، أو نشر إصدار، أو هدفاً مخصصاً. يمكن البدء من التغييرات أو Issue أو PR أو فحص فاشل. يظهر التقدم الحالي أولاً مع توسيع الخطوات والسجل عند الحاجة.

يفحص المسار المحدد التجهيز والالتزام وPush وPR وReview وActions والمخرجات وRelease وDMG وAppcast والنسخة المثبتة. تتطلب شروط Agent المقترحة موافقة. بعد انقطاع تُقرأ الحالة الفعلية مجدداً؛ نص Agent لا يثبت النجاح. الدمج ونشر الوسوم والتثبيت لها تأكيدات مستقلة.

<a id="intent"></a>
### فصل التغييرات المختلطة إلى التزامات

قسّم الملفات أو hunks من Diff إلى مجموعات برسائل مستقلة، بمساعدة Agent اختيارياً. يُفحص النقص والتكرار وتغيّر المستودع، ثم تُنشأ نقطة استعادة وتُنفذ الالتزامات بالترتيب.

يخضع كل التزام لفحص diff أو أمر تحقق تختاره. عند الفشل تُحاول استعادة HEAD وحدود الفهرس الأصلية، دون ضمان نجاح التراجع في كل ظرف؛ تبقى نقطة الاستعادة متاحة.

<a id="regression"></a>
### التحقيق في التراجعات داخل worktree معزولة

تشغيل `git bisect` دون تبديل مجلد عملك الحالي. تحقق آلي بأمر أو يدوي بتصنيف سليم أو معيب أو متجاوز. تُحفظ المرشحات والنتائج ورموز الخروج والمدة والمخرجات.

سلّم الأدلة إلى Agent للإصلاح وإعادة التحقق وإعداد PR. يجب أن يكشف الأمر المشكلة الفعلية؛ كثرة التجاوزات قد تترك أكثر من مرشح.

<a id="evidence"></a>
### أصل الكود وكبسولات الأعطال وسجلات النشاط

- **أصل الكود:** من السطر إلى الالتزام، ثم PR وIssue وReview وChecks المرتبطة عند توفر GitHub CLI.
- **كبسولات الأعطال:** تصدير الالتزام الأساسي والرقع والملفات غير المتتبعة المسموح بها والأمر الفاشل ومخرجاته وإصدارات الأدوات بصيغة `.gatto`. التحقق من البنية والبصمات قبل الاستعادة في worktree معزولة؛ لا تُشغّل الأوامر المرفقة تلقائياً. تُرشَّح المسارات الحساسة المعروفة والمحتويات المتعرف عليها فقط، لذا راجع قبل المشاركة.
- **Agents الخارجية:** ربط تغييرات الملفات والمراجع بعمليات Agent المعروفة التي كانت تعمل في المستودع، مع قوة الدليل. وجود عملية قيد التشغيل لا يثبت أنها صاحبة كل تغيير.

<a id="agent"></a>
### Agents لأكثر من رسائل الالتزام

يدعم Codex CLI وClaude Code وGemini CLI وOpenCode, DeepSeek Harness (dsh), Cursor Agent, GitHub Copilot CLI, Qwen Code وCLI مخصصة. تعليمات Git المدمجة تشمل مراجعة التجهيز والمسودات والتعارض والفروع واسترجاع التاريخ وصحة المستودع والإصدار؛ يمكن إرفاق أخطاء LFS وhooks والتوقيع والمزامنة الأصلية.

للمشروع والترجمة والبحث والتثبيت مسارات تنفيذ منفصلة. تُعاين إعادة كتابة README قبل تطبيقها. ردود Issue وPR تعتمد على المناقشة وdiff، تبقى قابلة للتحرير، ولا تُرسل إلا بعد التأكيد. يمكنك الاحتفاظ بإعداد CLI والنموذج الحاليين.

يمكن أيضاً إعداد API متوافقة مع OpenAI أو DeepSeek مباشرة دون تثبيت CLI لهذا الوضع. للمشروع والترجمة عناوين ونماذج مستقلة وقائمة نماذج وفحص قدرات وردود متدفقة. تُحفظ المفاتيح في سلسلة مفاتيح macOS. يقرأ Agent عبر API المشروع وينفذ الأوامر ويكتب ضمن مسارات مضبوطة؛ لا تحصل الترجمة على أدوات كتابة المشروع.

<a id="project-tools"></a>
### حفظ سياق المهمة وليس الفرع فقط

تحفظ **حالات العمل** الملفات المجهزة وغير المجهزة وغير المتتبعة، والفرع، والمسودات، والملف المحدد، والأهداف والروابط. تفحص الاستعادة حالة المستودع، ويمكن فتح worktree مستقلة. الملفات المتجاهلة مستبعدة، وليست الحالة نسخة احتياطية مستقلة.

| الأداة | الاستخدام |
| --- | --- |
| بحث في الشفرة | الملفات الحالية أو نسخة محددة أو تغييرات التاريخ عبر المستودعات المدارة؛ تصفية المجلد واللغة والامتداد ومعاينة الأدلة وإرسالها إلى Agent. مطابقة حرفية ونتائج محدودة. |
| تشغيل الأوامر | اكتشاف السكربتات وإضافة أوامر وتثبيتها؛ مخرجات مباشرة ومدة وحالة وإيقاف وإعادة وفتح الخدمات المحلية. تشغيل غير تفاعلي، المعاملات مصفوفة JSON. |
| قواعد التجاهل | شرح المصدر ومعاينة `.gitignore` المشتركة أو `.git/info/exclude` المحلية؛ إيقاف التتبع مع إبقاء الملفات. |
| هويات الإيداع | المؤلف والتوقيع حسب المستودع أو المجلد، المصدر الفعلي والفحص قبل الالتزام؛ منفصلة عن تسجيل دخول GitHub. |

من أدوات المشروع أو `⌘K`.

<a id="install-tools"></a>
### التثبيت مع الإعداد والتحقق

يقرأ الكتالوج GitHub Releases ويفصل التنزيل عن التثبيت. DMG وZIP بالتثبيت الأصلي، وحزم سطر الأوامر عبر Agent. تظهر المراحل والمخرجات وإعادة المحاولة.

**99 أداة وبيئة تشغيل**، كشف النسخ المحلية، تحديد متعدد وترقية جماعية. طوابير تثبيت وترقية حتى ثلاث مهام متزامنة، مع تسلسل كتابة Homebrew.

يكتمل PATH المطلوب وتسجيل الإضافات والتهيئة وترحيل الإعدادات قبل فحص الملف التنفيذي ونسخته. اكتمال التنزيل أو قول Agent لا يعوض التحقق. تبقى الصلاحيات والإعدادات الناقصة قابلة للمعالجة؛ الدخول للحساب وتفويض النظام يتطلبان المستخدم. قائمة المثبت تسجل تثبيتات GitGatto، لا كل تطبيقات Mac.

<a id="git-github"></a>
## Git وGitHub يومياً

- التجهيز والالتزام وdiff والرسم وblame وتاريخ الملفات والوسائط؛ بحث مركب بـSHA والمؤلف والمسار والنص والتاريخ والمرجع.
- الفروع والوسوم والبعيد وstash وworktrees والمقارنة وفروع الاسترجاع من reflog. ترتيب وsquash وتقسيم وamend وcherry-pick وrevert وreset؛ فحص الالتزامات المنشورة قبل إعادة الكتابة وتأكيد العمليات المدمرة.
- تعديل تعارضات merge وrebase وstash، متابعة أو تجاوز أو إلغاء؛ تشخيص LFS وhooks والأدوات.
- fetch وpull وpush لعدة مستودعات، مع نتائج منفصلة للتقدم والتأخر والتباعد والتعارض والفشل وإعادة الفاشل.
- مستودعات الحساب وبحث المطورين واللغة الطبيعية وStar وFork وclone والكود وREADME والإصدارات والمرفقات.
- صندوق للمراجعات والإشارات والفحوص الفاشلة؛ إنشاء وإدارة issues؛ ملفات PR وعلامات المشاهدة وتعليقات السطور والردود والمراجعات.
- Actions: التشغيل والسجلات والإعادة والإلغاء والمخرجات. تحديث الصفحة لا يبدأ كتابة بعيدة.

<a id="reading"></a>
## القراءة والترجمة

عرض Markdown والصور النسبية والكود وSVG والوسائط داخل التطبيق. كشف اللغة وإعداد ترجمة مستقل، مع ذاكرة حسب الأصل والمسار واللغة المستهدفة؛ تغيّر الأصل يمنع إعادة استخدام ترجمة قديمة. النص القصير أو الموجود باللغة المطلوبة قد يبقى كما هو. لا يحدث التزام README تلقائي.

<a id="appearance"></a>
## السمات والواجهة

ست سمات: ضباب خفيف, زجاج بلوري ناعم, وحدة التحكم, زمرد, فوليو, المشهد المضيء، تختلف في التخطيط واللوحات والشريط الجانبي وعناصر التحكم. المشهد المضيء تفصل ألوان الفاتح والداكن للخلفية واللوحات والنص والأزرار والحالات، مع إعدادات مرجان, ساحل, غابة, غسق.

أقسام قابلة للطي والتمرير، ومساحات قابلة للتحجيم، و11 لغة دون إعادة تشغيل. الإرشادات في مساعدة التطبيق.

<a id="start"></a>
## التثبيت والبدء

نزّل DMG من [Releases](https://github.com/Lincb522/GitGatto/releases/latest) واسحبه إلى التطبيقات. macOS 14+، Apple Silicon وIntel. النسخ المنشورة في [سجل التغييرات](CHANGELOG.md) وReleases؛ هذه الصفحة تصف المستودع الحالي.

| الاستخدام | المتطلب |
| --- | --- |
| Git المحلي والمزامنة العادية | Git ومصادقة Git / SSH للبعيد |
| GitHub وPR وIssue وActions | [GitHub CLI](https://cli.github.com/) مسجّل الدخول |
| Agent والترجمة والتثبيت به | CLI معدّة أو API متوافقة مع OpenAI / DeepSeek، بنموذج وصلاحيات تدعم المهمة |
| كشف Homebrew وترقيته | Homebrew |

افتح مستودعاً أو امسح يدوياً وحدد ما تضيفه، دون استيراد تلقائي لكل القرص. إعداد GitHub وAgents في الإعدادات؛ تحديث التطبيق عبر Releases وAppcast.

<a id="data"></a>
## البيانات والصلاحيات

القوائم والإعدادات والأهداف والتحقيقات والمحادثات والترجمات والتنزيلات ونقاط الاستعادة محلية، ويمكن نقل مجلد النسخ. Git وSSH وCLIs تستخدم مصادر اعتمادها المعتادة.

الحفظ المحلي لا يعني العمل الكامل دون اتصال: تُتصل GitHub، ويُمرر سياق Agent والترجمة المطلوب إلى CLI أو API المحددة. المعالجة اللاحقة تعتمد على الأداة وخدمة النموذج. راجع المرسل ولا تضع بيانات اعتماد في الأوامر أو المسودات أو الكبسولات. تعديل مجلدات النظام يخضع لتفويض macOS.

<a id="development"></a>
## التشغيل من المصدر

macOS 14+ وSwift 6.1+؛ إعداد Xcode في `project.yml`.

```sh
git clone https://github.com/Lincb522/GitGatto.git
cd GitGatto
swift package resolve
swift test --no-parallel
swift run GitGatto
```

أو افتح `GitGatto.xcodeproj` بمخطط `GitGatto`. بعد تغيير البنية أعد التوليد بـXcodeGen و`./scripts/generate-xcodeproj.sh`، دون تحرير ملف المشروع يدوياً. يستخدم SwiftUI وAppKit وWebKit وAVKit وAlamofire وSparkle؛ النسخ في `Package.resolved`.
