GitGatto — нативный клиент Git и GitHub для macOS. Состояние репозитория берётся из системного Git, удалённые операции выполняются через GitHub CLI, а Agents используют уже установленные и авторизованные CLI. Приложение собирает их состояния, шаги и результаты в одном представлении проекта.

## Зачем создан GitGatto

Полная доставка изменений часто проходит через терминал, редактор, GitHub, Actions и страницу выпуска. Если один шаг завершается ошибкой, приходится заново проверять ветку, индекс, журналы запуска и артефакты. При работе с Agent также важно контролировать его рабочий каталог, разрешения и соответствие контекста текущему репозиторию.

GitGatto появился из этих повседневных задач. Настоящий Git и существующие инструменты остаются на месте, а операции репозитория, совместная работа в GitHub, задачи Agents и сведения об ошибках соединяются в процесс, который можно проверить, остановить и продолжить.

## Отличительные возможности

### Цели проекта

«Доставить текущие изменения», «Доставка через GitHub» и «Полный выпуск» по порядку зависимостей проверяют индекс, коммиты, Push, Pull Request, Reviews, Actions, артефакты, Release, DMG, Appcast и установленную версию. Цель можно описать обычным языком и проверить полученные условия до запуска.

Каждый шаг читает фактическое состояние Git, GitHub или Mac. Выполненные шаги сохраняются после прерывания; неудачный запуск Actions можно передать Agent вместе с доказательствами. Слияние, публикация тега и установка требуют отдельных подтверждений.

### Поиск регрессий

`git bisect` запускается в изолированном worktree и не переключает текущее рабочее пространство. Автоматический режим выполняет выбранную команду проверки, ручной помечает кандидата как исправный, ошибочный или пропущенный. Кандидаты, коды завершения, время и вывод сохраняются. После нахождения первого проблемного коммита Agent может подготовить исправление, повторить проверку и открыть Pull Request.

### Восстановление репозиториев

Центр восстановления следит за локальными репозиториями, добавленными в GitGatto. Он по расписанию сохраняет незакоммиченные изменения, сразу создаёт точку при достижении порога файлов или строк и поддерживает ручное резервное копирование. Неизменившееся содержимое повторно не записывается.

Точка восстановления содержит Git bundle репозитория и копии незакоммиченных файлов. Для каждого репозитория сохраняется не более трёх точек по круговой схеме. Можно посмотреть объём, открыть папки, удалить одну точку или все копии репозитория и восстановить точку в новую копию репозитория. При смене каталога данные переносятся и проверяются до переключения.

### Agents для задач Git

Поддерживаются Codex CLI, Claude Code, Gemini CLI, OpenCode и пользовательские шаблоны CLI. Операции репозитория, перевод и установка программ используют независимые каналы, поэтому долгая задача не блокирует перевод документа.

Agent может обрабатывать полный вывод ошибок Git, Git LFS, hooks, подписи, веток, синхронизации, конфликтов, Pull Requests и Actions. Если индекс пуст, создание сообщения коммита может сначала добавить текущие изменения, затем выполнить commit или commit и Push. Переписанный README полностью отображается до того, как «Применить коммит» зафиксирует только этот документ.

## Git и GitHub

- Управление рабочим деревом, индексом, коммитами, Pull, Push, ветками, stashes и worktrees.
- Просмотр построчных Diff, графа коммитов, Blame, истории файла, изображений, SVG и видео из прошлых ревизий.
- Редактирование результатов конфликтов merge, rebase и stash с продолжением, пропуском или отменой операции.
- Загрузка доступных текущему аккаунту GitHub репозиториев; нечёткий поиск репозиториев и разработчиков, запросы обычным языком и подгрузка страниц.
- Просмотр кода, README, Pull Requests, Actions, Releases и файлов выпусков внутри приложения.
- Проверка файлов Pull Request, отметки о просмотре, построчные комментарии, ответы, Reviews, повторный запуск или отмена Actions и загрузка артефактов.
- Star, Fork и Clone. Локальное сканирование запускается вручную и позволяет выбрать репозитории вместо импорта всего диска.

## Документы, перевод и предпросмотр

- Отображение Markdown, относительных изображений и внутренних ссылок репозитория внутри GitGatto.
- Автоматическое определение языка и перевод через отдельный канал Agent; переводы сохраняются локально для каждой версии исходного текста.
- Предпросмотр исходного кода, изображений, исходника SVG и медиа из рабочего пространства, истории коммитов и файлов.
- README Agent перестраивает документ по файлам, зависимостям и существующим материалам репозитория, а не просто меняет формулировки.

## Каталог приложений и инструменты разработчика

- Поиск устанавливаемых приложений в GitHub Releases с настоящими значками, описанием, снимками экрана, версией и пакетами. DMG и ZIP использует локальный установщик, остальные форматы — Agent.
- Определение установленных версий и обновлений для 99 сред выполнения, инструментов сборки, контейнеров, облачных инструментов, баз данных и CLI.
- Установка и обновление в трёх параллельных очередях с множественным выбором и пакетным обновлением. Изменения Homebrew выполняются последовательно, чтобы не писать в Cellar одновременно.
- После установки Agent настраивает пользовательский PATH, регистрацию компонентов, инициализацию и перенос конфигурации, затем повторно проверяет исполняемый файл и версию.
- Сохранение этапов, исходного вывода и локализованных объяснений известных ошибок при загрузке, установке, настройке и проверке.

## Установка

Скачайте DMG из [Releases](https://github.com/Lincb522/GitGatto/releases/latest) и перетащите GitGatto в «Программы». Выпуски содержат универсальный бинарный файл для Apple Silicon и Intel и требуют macOS 14 или новее.

| Возможность | Требование |
| --- | --- |
| Локальные репозитории | Git |
| Репозитории GitHub, PR, Actions и удалённые операции | Авторизованная [GitHub CLI](https://cli.github.com/) |
| Agents | Хотя бы одна установленная и авторизованная поддерживаемая CLI |
| Проверка обновлений Homebrew | Homebrew |

Обновления в приложении, примечания и установщики поступают из GitHub Releases этого репозитория.

## Локальные данные и разрешения

- Настройки, список репозиториев, цели, расследования регрессий, диалоги и журналы Agents, загрузки и переводы остаются на Mac.
- При включённой защите Git bundles и копии незакоммиченных файлов сохраняются в Application Support или выбранном каталоге. Для репозитория остаётся не больше трёх копий, которые можно удалить в центре восстановления.
- Git, SSH, GitHub CLI и CLI Agents продолжают использовать собственные хранилища учётных данных. GitGatto не сохраняет токены, пароли и закрытые ключи.
- Pull, Push, Fork, комментарии, Reviews, Actions, установка приложений и изменение инструментов запускаются только после явного действия в приложении.

## Разработка

Требуются macOS 14 или новее и указанная в проекте версия Swift.

```bash
git clone https://github.com/Lincb522/GitGatto.git
cd GitGatto
swift package resolve
swift test
open GitGatto.xcodeproj
```

Используются Swift 6, SwiftUI, AppKit, WebKit и AVKit; для сети — Alamofire 5.12, для обновлений — Sparkle 2.9.6. Правила участия находятся в [CONTRIBUTING.md](CONTRIBUTING.md), границы системы — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
